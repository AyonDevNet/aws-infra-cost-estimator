Cloudly AWS Cost Input & Export Manager

Manual cost collection, tracking, and export for AWS services

How to Use This Tool

This is not an automatic pricing calculator. For each AWS service below, toggle the service on/off, enter your configuration details, and manually input the cost you've calculated or received from AWS. After filling in all required information, generate a summary and export your cost documentation to Excel.
